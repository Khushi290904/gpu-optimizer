# GPU Cost Optimizer 🚀

A cloud-based recommendation system that helps users select optimal GPU instances based on their workload requirements and budget constraints.

## ✨ Features

- **Intelligent Recommendations**: Suggests GPU instances
- **Cost Comparison**: View hourly, monthly, and spot pricing
- **Workload Analysis**: Input model type, dataset size, and training/inference needs
- **Region Support**: Multiple cloud regions available
- **Request System**: Request unavailable GPU instances

**Frontend**:

**Backend**:
